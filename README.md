# Library-Management-System
📚 Library Management System (Android App)

This project contains a Library Management System Android application developed using Java and TypeScript in Android Studio. The app is designed to manage library operations digitally, allowing users to organize books, track borrowing records, and manage library data efficiently from a mobile device.

## Features

📘 Add, update, and delete books

👤 Manage library members

🔄 Track book borrowing and returns

🔍 Search functionality

📱 Mobile-friendly and user-focused interface

## 🛠️ Tech Stack

Platform: Android

Languages: Java, TypeScript

IDE: Android Studio


## ⚙️ Installation

1. Clone the repository<br>
git clone https://github.com/Kayce-joy/Library-Management-System.git

2. Open the project in Android Studio<br>
Sync Gradle files

3. Run the application on an emulator or physical Android device

## 🎯 Project Goal

The goal of this project is to demonstrate mobile application development skills using Android Studio, focusing on structured data management, user interaction, and efficient library record handling.
